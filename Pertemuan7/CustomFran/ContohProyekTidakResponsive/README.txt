JELAJAH INDONESIA — VERSI NON-RESPONSIVE

Versi ini SENGAJA dibuat tidak responsive untuk demonstrasi pembelajaran.

Cara menunjukkan perbedaannya:
1. Buka index.html di desktop.
2. Buka DevTools (F12).
3. Aktifkan Device Toolbar (Ctrl+Shift+M).
4. Pilih ukuran HP, misalnya 390 x 844.
5. Bandingkan dengan versi responsive.

Perbedaan yang dapat diamati:
- Layout tetap memiliki lebar desktop.
- Card tetap 3 kolom.
- Galeri tetap 3 kolom.
- Multimedia tetap 2 kolom.
- Navbar tidak berubah menjadi layout mobile.
- Pada layar kecil akan muncul kebutuhan scroll/zoom horizontal.
- Form tetap lebar.

File:
- index.html
- form.html
- style.css

Tujuan:
Versi ini dibuat agar murid dapat melihat secara langsung kenapa
CSS media query dan responsive design diperlukan.
