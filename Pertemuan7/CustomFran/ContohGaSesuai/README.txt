CONTOH WEBSITE YANG SALAH — KRITERIA 1-3

Tema: Jelajah Indonesia

VERSI INI SENGAJA TIDAK MEMENUHI KRITERIA 1-3.

1. KELENGKAPAN INTEGRASI KOMPONEN — TIDAK SESUAI
- Beberapa link menggunakan href="#".
- Ada link menuju halaman yang tidak ada.
- Dropdown tidak tersedia.
- Form tidak lengkap: hanya text input.
- Tidak ada textarea/select/radio.
- Tidak ada video.
- Tidak ada peta.
- Hanya ada satu gambar.
- Tombol hanya memunculkan alert.
- Tabel sangat sederhana dan tidak mewakili data wisata dengan baik.
- Integrasi antar komponen tidak lengkap.

2. PENERAPAN TIPS & TRIK DESAIN — TIDAK SESUAI
- Warna dan gaya antar halaman tidak konsisten.
- Ukuran card tidak menggunakan sistem layout yang jelas.
- Spacing tidak konsisten.
- Tidak ada responsive design.
- Navigasi tidak memiliki dropdown.
- Typography tidak konsisten.
- Footer sederhana dan tidak konsisten dengan header.
- Beberapa styling inline, beberapa internal CSS, sehingga tidak konsisten.

3. KERAPIAN & KUALITAS KODE — TIDAK SESUAI
- Struktur kode sengaja dibuat kurang rapi.
- Banyak inline style.
- CSS internal dan eksternal dicampur.
- Indentasi tidak konsisten.
- Tidak menggunakan struktur semantic HTML dengan baik.
- Tidak ada komentar/pengelompokan CSS yang baik.
- Nama class sangat minim.
- Ada link ke file yang tidak tersedia.

TUJUAN DEMO:
Tampilkan versi ini kepada murid lalu bandingkan dengan versi yang benar.
Murid dapat diminta menemukan sendiri masalah pada kriteria 1, 2, dan 3.

PERBANDINGAN:
BENAR  -> semua komponen terintegrasi, desain konsisten, kode rapi.
SALAH  -> komponen hilang/tidak berfungsi, desain berantakan, kode tidak terstruktur.
