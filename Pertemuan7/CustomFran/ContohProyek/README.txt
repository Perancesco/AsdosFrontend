JELAJAH INDONESIA — WEB WAJIB PROYEK

Isi:
- index.html : halaman utama
- form.html  : halaman formulir
- style.css  : seluruh styling eksternal

Ketentuan yang dipenuhi:
1. 2 halaman HTML saling terhubung.
2. Struktur header/konten/footer konsisten.
3. 1 tabel HTML data terstruktur.
4. 1 form lengkap: text, radio/pilihan, select, textarea, submit.
5. Multimedia: video YouTube + peta Google Maps + galeri gambar.
6. Menu navigasi dengan dropdown yang berfungsi menggunakan <details>.
7. Seluruh styling berada di CSS eksternal.

Catatan:
- Video, peta, dan gambar galeri menggunakan sumber online sehingga perlu koneksi internet saat dibuka.
- Formulir bersifat demo dan menampilkan pesan berhasil tanpa backend/database.
